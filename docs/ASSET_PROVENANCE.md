# Asset provenance

All prototype C# source, triangle/circle textures generated in `StationView`, and synthesized chime/boing waveforms in `AudioFeedback` were authored for this project. No external game art, sound, layouts or paid Asset Store packages were used.

Unity, URP and uGUI (including TextMeshPro) remain subject to their package licences. TMP's default font is imported from the official installed package by the preparation command. Orbitron/Inter and final production assets have not been imported. The ten DOCX files under `docs/specifications` are the user-supplied project references.
