# Asset provenance

- Original meshes: `art-source/build_models.py`, created for this project in Blender 4.3.2. Editable source: `art-source/ZeroGCargo-Models.blend`. Nine FBX exports include four shuttle variants, Dock, Meteorite, EnergyBarrier, GravityWell and StationDeck. No paid or third-party game meshes were used.
- `docs/visuals/3d-models-preview.jpg` is a real Blender render of those exported designs, not an in-engine screenshot. The old placeholder SVG is retained as historical documentation.
- `Resources/Art/StationBackdrop.png` is an original image-generation output created for this project. It is used behind menus. The modelled station deck is used during gameplay.
- Audio waveforms are original synthesized clips generated in AudioFeedback. No external recordings were used.
- Orbitron and Inter were downloaded from the official google/fonts repository. Their SIL Open Font Licences accompany the TTFs in `Resources/Fonts`. Unity generates TMP font assets on preparation.
- Unity, URP and uGUI/TMP are subject to their package licences. The original ten DOCX references were supplied by the user.

`docs/visuals/sector-50-blender-preview.jpg` renders the bundled sector-50 positions using the same Blender models. It is a layout/asset preview, not evidence of Unity rendering or a phone screenshot.
